# Security policy

Report a potential vulnerability privately through this repository's
[GitHub private vulnerability reporting](https://github.com/pcvantol/djconnect-firmware/security/advisories/new)
form. Do not publish proof-of-concept details in a public issue before the
maintainer has assessed the report.

This repository distributes public firmware release artifacts, checksums, and
release metadata. For a source-code concern, include the affected artifact
version and checksum so the report can be traced to its source release.

For non-security feedback, use the normal GitHub issue tracker.
